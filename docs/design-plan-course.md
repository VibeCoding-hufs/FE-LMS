## 3. 컴포넌트 상세 (Components)

### 3-1. 헤더 (로그인 후)
- 좌측: 언어 선택 드롭다운
- 중앙: HUFS 로고 + 교명
- 우측: 프로필 사진 + 이름(한서연) + 알림 뱃지 3개 (메시지/알림/공지) + 로그아웃 버튼
- 알림 뱃지: Primary 틸 원형, 흰 숫자 텍스트

### 3-2. LNB — 좌측 과목 네비게이션
- 최상단: **수강과목** 제목 (흰 배경 카드)
- 학기 표시: `2026-1학기`
- 과목 선택 드롭다운 (`[서울]웹프로그래밍 ▼`)
- 수강 인원 정보: `수 1 2 3 (3503)`

메뉴는 **카테고리 박스** 단위로 그룹화하며, 각 박스는 접기/펼치기 가능:

```
┌─────────────────────┐
│  📖 강의            │  ← 그룹 헤더 (클릭 시 접기/펼치기)
│  · 강의계획서        │
│  · 과목 공지사항     │
│  · 강의자료          │
│  · 온라인강의        │
├─────────────────────┤
│  ✏️ 과제            │
│  · 과제              │
│  · 팀플              │
│  · 열린게시판        │
│  · [+ 카테고리 추가] │  ← 교수자 전용 기능
├─────────────────────┤
│  📊 성적            │
│  · 시험              │
│  · 성적              │
└─────────────────────┘
```

- 그룹 헤더: Primary 틸(`#3C8794`) 배경, 흰 텍스트, 우측 `▲/▼` 토글 아이콘
- 하위 항목: 흰 배경, `·` 불릿, 좌측 들여쓰기
- 현재 선택 항목: Primary 색상 강조 + 좌측 액센트 바
- **카테고리 추가 버튼** (`[+ 카테고리 추가]`): 교수자 권한일 때만 표시, 점선 버튼 스타일

### 3-3. 메인 콘텐츠 — 섹션 카드
각 섹션은 아이콘 + 제목 헤더 + 리스트 아이템 구조의 **카드 박스**:

| 섹션 | 아이콘 | 내용 |
|------|--------|------|
| **공지사항** | 📢 (노란/주황 아이콘) | 제목 + 날짜 리스트, 더보기 링크 |
| **질의응답** | ❓ (회색 아이콘) | 질문 제목 + `해결`/`미해결` 상태 뱃지 |
| **강의자료** | 📁 (노란 폴더 아이콘) | 자료명 + 날짜 리스트, 더보기 링크 |
| **과제** | ✏️ (연필 아이콘) | 과제명 + `진행중`/`종료` 상태 뱃지, 더보기 |

**카드 구조 공통:**
- 상단 헤더: 아이콘 + 섹션 제목 (좌측 정렬)
- 리스트: `·` 불릿 + 제목 링크 + 날짜/상태 (우측 정렬)
- 하단: `더보기»` 링크 (회색)
- 카드 간격: 섹션 간 마진으로 구분

### 3-4. 우측 사이드바 — 할일 목록 (투두메이트 스타일)

D-day가 지정된 할일(과제·시험·팀플 등)을 **마감 오름차순**으로 정렬해 보여주는 단일 패널.

```
┌─────────────────────┐
│  📋 할일             │
├─────────────────────┤
│  ☐  과제 6. 사원DB   D-1  │  ← D-day 임박순 정렬
│  ☐  중간고사          D-3  │
│  ☐  과제 7. 뷰       D-6  │
│  ☐  팀 프로젝트 발표  D-9  │
│  ☐  기말고사         D-14 │
│  ✓  과제 5. 비만도   완료  │  ← 완료 항목은 하단에
│  ✓  과제 4. 무지개꽃  완료  │
└─────────────────────┘
```

**정렬 규칙**
- 미완료 항목: D-day 오름차순 (D-1 → D-2 → …)
- 완료 항목: 미완료 항목 아래 별도 그룹, 최신 완료순

**각 아이템 구성**
- 좌측: 체크박스 (`☐` 미완료 / `✓` 완료)
- 중앙: 할일 제목 (링크, 해당 과제/시험 페이지로 이동)
- 우측: D-day 뱃지

**D-day 뱃지 색상 규칙**
| 조건 | 배경색 | 텍스트 |
|------|--------|--------|
| D-1 ~ D-3 | `#E05555` (빨강) | 흰색 |
| D-4 ~ D-7 | `#E08A00` (주황) | 흰색 |
| D-8 이상 | `#3C8794` (틸) | 흰색 |
| 완료 | `#CCCCCC` (회색) | `완료` |

**인터랙션**
- 체크박스 클릭 → 완료 처리, 취소선 + 하단 완료 그룹으로 이동
- 항목 클릭 → 해당 과제/시험 상세 페이지로 이동

### 3-5. 푸터 (로그인 후 추가)
- 기존 3개 컬럼(교육현황/커뮤니티/소개) + **마이페이지** 컬럼 추가
- 마이페이지 항목: 개인정보, 수강과목, 홈런파일함
