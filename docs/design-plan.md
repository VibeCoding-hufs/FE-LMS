## 3. 레이아웃 구조 (Layout Structure)

```
┌─────────────────────────────────────────────────────┐
│                     HEADER                          │
│  [언어선택]  [로고 + 교명]          [로그인 버튼]   │
├───────────────────────────┬─────────────────────────┤
│      MAIN CONTENT (좌)    │    SIDEBAR (우)         │
│  ┌─────────────────────┐  │  ┌───────────────────┐ │
│  │    일정 (달력)       │  │  │  D-DAY 할일 목록  │ │
│  │  YYYY.MM 월별 뷰    │  │  │                   │ │
│  └─────────────────────┘  │  │  D-3  과제 제출   │ │
│  ┌─────────────────────┐  │  │  D-7  중간고사    │ │
│  │  이번 주 수업 시간표 │  │  │  D-14 기말 발표   │ │
│  │  월~금 요일별 블록  │  │  │  ...              │ │
│  │  과목명 / 시간 / 장소│  │  │  (디데이 오름차순)│ │
│  └─────────────────────┘  │  └───────────────────┘ │
│                           │                        │
├───────────────────────────┴─────────────────────────┤
│                     FOOTER                          │
│  [로고] 저작권 정보 / 주소 / 연락처  │ 사이트맵   │
└─────────────────────────────────────────────────────┘
```

### 레이아웃 세부 사항
- **전체 너비**: 고정 너비 (약 1036px 기준)
- **좌우 비율**: 메인 콘텐츠 약 62% / 사이드바 약 38%
- **배경**: Body는 `#EDEDED`, 콘텐츠 카드는 흰 배경에 그림자 또는 border
- **형태**: 상단 헤더가 약간 굴곡진 장식(arch) 모양

## 4. 컴포넌트 상세 (Components)

### 4-1. 헤더 (Header)
- 상단 좌측: 언어 선택 드롭다운 (`한국어` / `English`)
- 중앙: HUFS 로고 + "한국외국어대학교 / e-Class (LMS/TMS)" 텍스트
- 우측: 로그인 버튼 (흰 배경, 아이콘 포함)
- 배경: 흰색/투명, 상단에 아치형 장식 효과
- GNB(상단 내비게이션) 없음

### 4-3. 일정 (Calendar Widget)
- 섹션 타이틀 배경: Primary(`#3C8794`)
- 타이틀 텍스트: 흰색, "일정"
- 우측 목록 아이콘 버튼
- 달력: 7열 그리드, 이전/다음 달 이동 버튼
- 오늘 날짜 강조: `#5FB1BF` 배경의 원형 하이라이트
- 일요일: 빨간색, 토요일: 파란색

### 4-4. 이번 주 수업 시간표 (Weekly Timetable)
- 섹션 타이틀 배경: Primary(`#3C8794`), 텍스트: 흰색, "이번 주 시간표"
- **표시 범위**: 현재 날짜 기준 이번 주 월~금
- **구조**: 요일(열) × 시간(행) 그리드 또는 요일별 수직 카드 리스트
- **각 수업 블록 표시 항목**:
  - 과목명 (굵게)
  - 시간 (예: 09:00–10:30)
  - 강의실/장소
  - 담당 교수 (선택)
- **오늘 요일 컬럼 강조**: 배경색 또는 테두리로 현재 요일 하이라이트
- **수업 없는 날**: 빈 칸 또는 "수업 없음" 표시
- **색상**: 과목별 고유 색상 태그(선택), 기본은 Primary 계열

### 4-5. D-day 할일 목록 (Sidebar — D-day Todo)
- **위치**: 우측 사이드바 전체 또는 상단 고정 영역
- **컨셉**: TodoMate 스타일 — 디데이가 설정된 할일만 표시
- **정렬**: D-day 오름차순 (가장 임박한 항목이 최상단)
- **각 항목 표시**:
  - `D-N` 배지 (N일 남음, Primary 색상 배경)
  - `D-0` 당일: 강조 배지 (빨간색 또는 주황색)
  - `D+N` 지난 항목: 회색 처리 또는 취소선
  - 할일 제목
  - 마감일 (소자, 회색)
  - 체크박스 (완료 처리)
- **입력**: 하단 `+ 할일 추가` 버튼 → 제목 + 날짜 입력 인라인 폼
- **완료된 항목**: 취소선 + 투명도 낮춤, 목록 하단으로 이동
- **빈 상태**: "마감일이 있는 할일을 추가해보세요" 안내 문구



### 4-7. 푸터 (Footer)
- 배경: 어두운 회색 (`#4C4C4C` 계열)
- 좌측: HUFS 로고 + 저작권 / 주소 / 연락처
- 우측: 사이트맵 (`교육현황`, `커뮤니티`, `소개` 각 컬럼)
- 개인정보처리방침 링크

## 7. 접근성 (Accessibility)

- 본문 바로가기 (`#containerWrap`) 링크 제공
- 달력 테이블에 `aria-label` 지정 ("2026년 5월 달력")
- 버튼에 명시적 텍스트 레이블 ("이전달이동", "다음달이동")
- 이미지에 `alt` 속성 적용
